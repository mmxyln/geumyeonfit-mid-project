# Design Guide

## Screen A — 오늘 홈
- A-1 오늘의 흡연 기록: 현재 상태를 첫 화면에서 즉시 인지 (P01)
- A-2 빠른 기록 CTA: 한 번의 탭으로 기록 흐름 시작 (P07)
- A-3 이번 주 변화 카드: 장기 진행을 수치로 비교 (P01)

## Screen B — 빠른 기록 BottomSheet
- B-1 1개비 기록: 데모용 로컬 표시 변경만 수행 (P07)
- B-2 실제 저장되지 않음을 명시 (P01)

## Screen C — 흡연 추세
- C-1 Loading: GET 진행 상태 표시 (P01)
- C-2 Error + 다시 시도 (P09)
- C-3 Empty: 다음 행동 안내 (P09)
- C-4 Data: 날짜별 흡연량과 목표 상태 표시 (P01)

## Screen D — 감량 계획
- D-1 7일 단계적 목표 (P02)
- D-2 누락/실패 후 전체 초기화 대신 이어가기 (P03, P05)
- D-3 AI 분석 결과: 미리 준비된 임의 결과, 실제 AI 호출 없음
